# Aethyme Agent Contract Kit v1

This local kit gives coding agents the templates and schemas needed to prepare a
repository for portable agent operating contracts.

The kit is copied into target repositories under:

`.aethyme/agent-contracts/v1/`

Use these files as reference material only. The actual repository contracts live
under `AGENTS.md` and `.agents/*.yaml`.

Do not commit `.aethyme/`; Aethyme adds it to `.git/info/exclude` when the kit is
installed from the app.
