Developer Preview for macOS

Local observability for operators and AI agents.

Aetower helps you inspect process pressure, wakeups, memory, energy friction, diagnostics, and local agent impact without sending your machine data to a cloud service.

Local-first

Runtime history and diagnostics stay on your Mac unless you export them.

Conservative defaults

Endpoint Security, telemetry, and automatic MCP registration are off by default.

Installer first

Use the PKG for the default install path; DMG, Homebrew, ZIP, and source are secondary options.
